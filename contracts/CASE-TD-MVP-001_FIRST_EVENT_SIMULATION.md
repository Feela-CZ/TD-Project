# CASE-TD-MVP-001 — First event simulation

**Status:** READY FOR EXECUTION  
**Authority:** DEC-TD-001  
**Project phase:** PRE-IMPLEMENTATION → executable prototype

## Objective

Create a deterministic TypeScript core and Node.js headless event/Monte Carlo simulator for the approved Tower Defense MVP rules, then independently verify the resulting artifact and simulation outputs.

## Scope

- Existing MVP match, economy, combat, wave, creep-loop, upgrade, mutation, targeting, projectile, and overload rules from the canonical handoff.
- The temporary simulation assumptions recorded in DEC-TD-001.
- Representative multi-wave openings required by the handoff: no upgrades; each offense L1; each offense L2; three offense L1s; interest-heavy openings; and mutation-L1 counterbuilds.

## Explicit exclusions

- Visual client, UI architecture, game-engine choice, packaging, multiplayer, fog of war, and parked progression systems.
- Silent rebalance of any canonical number.
- Any claim about balance without executed simulation evidence.

## Acceptance criteria

1. The simulator runs reproducibly from Node.js and exposes deterministic seeded runs.
2. Simulated rules cover waves, spawning, looping creeps, firing-sector targeting, projectile travel, rewards, interest, permanent upgrades/mutations, Overdrive, and overload loss.
3. Monte Carlo output reports, for each required opening: kills per lap, active creeps over time, average reward, energy over time, overload wave if applicable, run variance, and build comparison.
4. Results are generated by actual execution, not inferred calculation or narrative.
5. Independent review, functional verification, and audit certification support the final management report.

## Required evidence and gates

- Gate 1: Contract and canon consistency confirmed.
- Gate 2: Runnable implementation and generated simulation artifacts.
- Gate 3: Independent review plus simulation/functional verification.
- Gate 4: Reproducible headless integration run.
- Gate 5: Auditor-certified receipt before case closure.

## Known risk

The aggressive compound-interest curve may dominate early strategy. It will be measured and reported; it will not be changed within this case.
